# CSS - Perspective

```
transform: perspective(100rem) rotateY(30deg) rotateX(10deg);
```

- `perspective()` gives the element the distance of the exit point, from the screen.
- `rotateY()` is the vertical axis. Imagine a line going through the top-middle to the bottom-middle, and rotate along that axis.
