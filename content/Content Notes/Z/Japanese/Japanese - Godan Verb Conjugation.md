# Japanese - Godan Verb Conjugation

Godan verbs are verbs that end un a u-sound. Only some of the verbs that end in る are godan, most are ichidan.
They are called godan because you take the ending, and you walk it up and down the hiragana column for each vowel to conjugate.

For instance, the verb `あるく`or "to walk."

If we imagine the kana chart, in japanese vowel order, we have ka, ki, ku, ke, ko.
To conjugate aruku, we replace the last syllable, `ku`, with different syllables _in the same column_.

here are what each of the vowel endings mean:

| Vowel Ending | Example Syllables | Stuff To Add At the end                | Conjugation　（also called form)                                                                                                                                                                                                                                         |
| ------------ | ----------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| a            | か, が、た            | -nai                                   | **Short negative** form. Its `verb + a-suffix + nai`, so `arukanai` for "to not walk".                                                                                                                                                                                 |
| i            | き、ぎ、ち             | -desu, -masen, -deshita, -masendeshita | The polite **present** and **future** form, a.k.a. "The ます　form". So present/future is `verb + i-suffix + masu`, present/future negative is `verb+i-suffix+masen`, past positive is `verb + i-suffix + mashita`, and past negative is `verb + i-sufix + masendeshita`. |
| u            | く、具、つ             |                                        | Plain/Dictionary form, also used for the **present** and **future**.                                                                                                                                                                                                   |
| u            |                   | -any noun                              | You can attach it to a noun to make a composite word. For instance, `arukuriki`, for "walking power"?　歩く力                                                                                                                                                              |
| e            | け、げ、て             |                                        | Imperative, command. `aruke`! "Walk!"                                                                                                                                                                                                                                  |
| e            |                   | -ba                                    | Hypothetical. "arukeba" means "if walk", as in "If we walked, we'd go somewhere".                                                                                                                                                                                      |
| e            |                   | -ru                                    | Potential form. How is that different from hypothetical you ask? Well, this is "can", so like "I can walk", "I have the ability to walk".                                                                                                                              |
| o            | こ、ご、と             | -u                                     | Volitional, as in expressing volution or will to do something. "arukou"! "Let's walk!"                                                                                                                                                                                 |

#### Example

- Verb: はなす、to speak.
  - はなせます, I talk, formally.
  - はなせました、I spoke, formally.
  - はなそう！ Let´s speak!

#### Exceptions: verbs that end in う

- for godan verbs that end in exactly う, only in the case of "a", they get transformed into わ。
- so, うたう　(to sing) becomes utawanai, not utaanai.
