# HTML Media Source Extensions

- Spec: https://www.w3.org/TR/media-source/
- Essentially, a way to extend HTMLMediaObject with Javascript to allow for adaptive streaming, such as [[HLS - HTTP Live Streaming]].
- So, you have an HTML element in HTML, but you can add `MediaSOurce`s to it.
- So this is an extension to the HTML `audio` elements which is not super useful for bardic tools because they have non-deterministic looping.
